Why EtherTransfer?

Zero Configuration

Just plug in an Ethernet cable and open the app on both computers. There are no IP addresses to type, no settings to tweak, and no routers required.

100% Offline

All files go directly through the cable from one computer to the other. It works completely offline, meaning you don't need an internet connection.

Keeps Folders Intact

Transfer entire folders full of files at once. The app keeps everything perfectly organized exactly the way it was, without you needing to zip anything first.

Windows & Linux

Easily send files between different operating systems. The app automatically handles all the technical differences behind the scenes.

Privacy & System Policy

EtherTransfer operates 100% offline. However, the installer modifies specific system settings to allow seamless computer-to-computer transfers.

Network & Firewall

The installer automatically whitelists EtherTransfer in the Windows Defender Firewall. On Linux, it detects and modifies UFW, Firewalld, or iptables to open Port 8840 (TCP/UDP) for peer discovery.

System Dependencies

On Linux, the script automatically uses your package manager (apt, dnf, pacman, etc.) to install the network-manager package if it is missing, as it is required for monitoring interface connectivity.

Zero Telemetry Guarantee

EtherTransfer does not include background tracking services, telemetry agents, or startup analytics hooks. Absolutely no data ever leaves your local network.
