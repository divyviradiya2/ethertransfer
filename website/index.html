Project Overview

EtherTransfer was built to solve the simple problem of moving large datasets between local machines without relying on external drives or cloud storage.

🔌

Direct Connection

Bypasses the internet and local routers. Speeds are limited only by your hardware—meaning your Network Interface Cards (NICs) and the category of your Ethernet cable.

🔒

Local Network Only

All data is transmitted via direct TCP connections. There are no telemetry servers, accounts, or third-party tracking. It works entirely offline.

💻

Cross-Platform

Written in C# with Avalonia UI. You can send files natively between Windows and Linux machines without worrying about file system formats (like NTFS vs ext4).

📁

Directory Preservation

Supports dragging and dropping multiple nested directories. The application recreates the exact folder structure on the receiving machine.

Usage Guide

1

Hardware

Plug an Ethernet cable directly into the network ports of both computers. Ensure both network adapters are enabled.

2

Launch

Open EtherTransfer on both machines. They broadcast UDP packets to automatically discover each other on the link-local network.

3

Transfer

Select your files on the sender machine. The receiver will get a prompt to accept the incoming TCP transfer.
